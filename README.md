## 🌟 Giới Thiệu

> **"Bạo lực học đường không chỉ là vấn đề của riêng ai — đó là vấn đề của cả xã hội."**

Đây là bộ **slide thuyết trình tương tác 14 slide** về chủ đề **Phòng Chống Bạo Lực Học Đường**, được xây dựng bằng **HTML5, CSS3 và JavaScript** hiện đại, sử dụng framework thuyết trình mạnh mẽ nhất hiện nay — **Reveal.js**.

Dự án được thực hiện bởi **Nhóm 6** như một phần của bài thuyết trình môn học, nhằm mục đích nâng cao nhận thức cộng đồng về vấn nạn bạo lực học đường.

### 🎯 Mục Tiêu Dự Án

| Mục tiêu | Mô tả |
|:--------:|-------|
| 📚 **Giáo dục** | Nâng cao nhận thức về bạo lực học đường |
| 🛡️ **Phòng ngừa** | Trang bị kiến thức để phòng tránh |
| 💪 **Hành động** | Khuyến khích học sinh lên tiếng |
| 🌈 **Lan tỏa** | Truyền tải thông điệp yêu thương |

## 🚀 Cách Chạy

### ⚡ Cách 1: Mở Trực Tiếp (Nhanh Nhất)

Chỉ cần **nhấp đúp** vào file `index.html` → trình duyệt sẽ tự động mở slide.

### 🔥 Cách 2: Dùng Live Server (Khuyến Nghị)

**VS Code:**
1. Cài extension **Live Server**
2. Click chuột phải vào `index.html`
3. Chọn **"Open with Live Server"**

**Hoặc dùng Python:**
```bash
python3 -m http.server 8000
# Mở: http://localhost:8000
```

**Hoặc dùng Node.js:**
```bash
npm install -g http-server
http-server -p 8000
# Mở: http://localhost:8000
```

### ☁️ Cách 3: GitHub Codespaces

```bash
# 1. Mở Codespaces
# 2. Chạy lệnh
python3 -m http.server 8000

# 3. Click "Open in Browser" ở popup
```

## 🖼️ Tải Ảnh Tự Động

Dự án có sẵn script `tai_anh.py` để tự động tải 14 ảnh từ **Pexels API**.

### 📝 Các Bước

**Bước 1: Lấy API Key miễn phí**

```
1. Vào https://www.pexels.com/api/
2. Đăng ký tài khoản
3. Nhấn "Generate API Key"
4. Copy key (dạng: 563492ad6f91700001000001...)
```

**Bước 2: Dán key vào file `tai_anh.py`**

```python
PEXELS_API_KEY = "DÁN_KEY_CỦA_BẠN_VÀO_ĐÂY"
```

**Bước 3: Cài đặt & chạy**

```bash
# Cài thư viện
pip install requests

# Chạy script (Linux/Mac)
python3 tai_anh.py

# Chạy script (Windows)
python tai_anh.py
```

**Kết quả:**

## 🎨 Tùy Chỉnh

### 🎨 Đổi Màu Chủ Đạo

Mở `style.css`, sửa phần `:root`:

```css
:root {
    --xanh: #1E88E5;      /* Màu xanh dương */
    --xanh-dam: #0D47A1;   /* Xanh đậm */
    --do: #E53935;         /* Màu đỏ */
    --vang: #FFC107;       /* Màu vàng */
    --xanh-la: #43A047;    /* Xanh lá */
    --tim: #7B1FA2;        /* Màu tím */
    --cam: #FB8C00;        /* Màu cam */
}
```

### 🎬 Đổi Hiệu Ứng Chuyển Slide

Mở `script.js`:

```javascript
transition: 'slide',  // 'slide' | 'fade' | 'convex' | 'concave' | 'zoom'
```

### ➕ Thêm Slide Mới

Copy 1 section trong `index.html`:

```html
<section class="slide-noi-dung">
    <div class="header-xanh">
        <h2><i class="fas fa-star"></i> TIÊU ĐỀ MỚI</h2>
    </div>
    <div class="container-2-cot">
        <div class="cot-text">
            <ul class="danh-sach-animation">
                <li class="fragment slide-in-left">Nội dung 1</li>
                <li class="fragment slide-in-left">Nội dung 2</li>
            </ul>
        </div>
        <div class="cot-anh fragment zoom-in">
            <img src="images/anh_moi.jpg" alt="Ảnh">
        </div>
    </div>
</section>
```
